# Northside Studio — Demo Web

Demo moderna y responsive para una barbería ficticia, creada como pieza de portafolio para servicios de desarrollo web.

## Características

- Diseño responsive para móvil, tablet y escritorio
- Hero comercial con llamadas a la acción
- Servicios y precios
- Galería visual
- Sección de contacto
- Reserva por WhatsApp
- Menú móvil
- Diseño fácil de personalizar para clientes reales

## Personalización

Se pueden cambiar rápidamente:

- Nombre del negocio
- Colores y tipografía
- Servicios y precios
- Fotografías
- Horarios
- Ubicación
- Redes sociales
- Número de WhatsApp

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Uso

Abrir `index.html` en el navegador o publicar el repositorio con GitHub Pages.

> Este proyecto es una demo de portafolio. Los datos del negocio son ficticios.
